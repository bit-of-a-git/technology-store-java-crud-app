## **About the Project**

This Java MVC CRUD app was submitted as the final assignment for South East Technological University's Programming module. This is a menu-driven, terminal-based app that can store details about Smart Bands and Smart Watches. Information entered via the app is persisted in XML files.

## **Features**

- Add, list, update, and delete devices via the CRUD menu
- Generate reports, e.g. the most expensive devices 
- Search devices by attributes such as size and material
- Sort devices by price, ascending or descending
- Save and load WearableDevice databases to XML files

## **Installation**

1. Clone the repository:

    ```bash
    git clone https://github.com/bit-of-a-git/technology-store-java-crud-app.git
    ```

2. Open in your IDE - IntelliJ IDEA recommended

3. Go to src/main/Driver

4. Run Driver - for IntelliJ IDEA, the button is at the top of the window

## **Usage**

Upon running the app, a main menu is shown which gives users the option to go to further submenus. These submenus include:

- CRUD
- Reports
- Search
- Sort
- Save
- Load

Users may navigate to and from these submenus by entering their respective numbers into the terminal and pressing the return key.
